# 使用指南

[文档中心](README.md) · [API 参考](api.md)

## 创建文本与文件分享

文本分享支持普通文字和 Markdown，可在编辑与预览之间切换。支持粘贴图片和通过工具栏插入图片链接；PNG、JPEG、GIF、WebP 每张最多 1 MiB，图片随文本一起保存。文件分享支持拖拽和批量选择，单文件默认最大 10 GiB，选择存储后上传；多个文件可组成合集。

| 选项           | 说明                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 自定义链接名称 | 1–100 个英文字母、数字、短横线或下划线；留空自动生成                           |
| 有效期         | 5 / 10 / 30 分钟，1 / 3 / 6 / 12 小时，1 / 3 / 7 / 14 / 30 / 90 天，或长期保留 |
| 访问密码       | 可选，访客需验证后查看                                                         |
| 最多查看次数   | 0 表示不限，正整数表示上限                                                     |
| 文件备注       | 直接展示在上传表单中                                                           |

站点默认有效期也会显示，即使它不在常用选项内。有效分享的链接名称不能重复；过期或查看次数耗尽后可重新使用原后缀。成功文件会移出队列，重试只处理剩余项。

未登录或没有对应分享权限时，分享表单控件禁用；登录入口仍可点击。文件备注和其他分享选项直接展示，无需展开。

文件上传的保存位置只列出已启用、可写且已授权的存储；只读存储不会出现在列表中。没有可选位置时，管理员应检查存储的只读设置、公开标记及密钥授权。

本地上传直接写入目标目录中的隐藏临时文件，完成校验和磁盘刷盘后发布，无需再次复制整个文件。进度到 100% 后显示“正在保存…”时，仍需等待刷盘和分享记录保存；S3 上传还需等待服务端将暂存文件写入远程存储。

文件管理中修改名称只改变显示名。分享到期后原文件仍保留。删除时默认同时删除原文件，也可取消勾选“同时删除存储中的原文件”以仅删除记录；合集会删除全部子文件，存储失败时可重试。已登录管理员打开失效分享仍可查看、预览和下载现有内容，页面标明失效原因，且不会消耗查看次数。

登录的 API Key 用户也可打开本人创建的失效分享，文本、文件和合集均支持；页面显示“创建者查看”和失效原因，预览、下载、刷新都不消耗查看次数。其他用户和访客仍受有效期、密码和次数限制。存储文件已删除、来源配置变化或创建者凭据被停用时，不能绕过来源保护读取文件。

创建者和管理员在管理界面可看到当前分享密码，编辑框直接修改即可；分享预览页不展示密码，预览接口也不返回密码。清空已显示的密码或勾选取消保护可移除密码。不修改密码时保留现有保护。新建或重新设置的密码保存为验证哈希及加密副本。旧分享只有不可逆哈希，无法还原原密码，管理页会提示重新设置；原密码验证仍有效。

文本、文件及合集创建后，结果区的只读文字框可选中并手动复制。格式为 `链接：分享页面地址`，有密码时另起一行 `密码：分享密码`，无密码时省略密码行。下方统一提供“复制链接”“复制分享文字”“打开分享”按钮。复制结果使用创建时的链接、密码，随后修改创建表单不会改变已有结果。

## 设备互传

“系统设置 → IP 归属地”独立选项卡支持手动加载、更新和卸载 IP2Location LITE DB3 IPv4 BIN，作为全站共享的定位数据库。数据库需管理员自行下载、解压并更新，加载后立即生效，重启保留。未加载数据库时不显示归属地，IPv6 始终不显示位置。加载后，IPv4 的国家、省份显示在授权区和连接信息中，国内省名转为中文；未查到显示“未知”，内网和本机单独标识。归属地描述网络出口，可能与设备实际位置不同。互传操作日志开启时记录对应归属地，卸载不删除旧日志。详见[部署文档](deployment.md#可选-ip-归属地数据库)。

CloudPaste uses the IP2Location LITE database for [IP geolocation](https://www.ip2location.com).

打开 `/transfer`。管理员或同时拥有文本、文件分享权限的 API Key 可以创建连接；另一台设备无需登录，输入配对码即可请求加入，创建者确认后双方才能发送文字和文件。

“高级连接设置”默认使用站点的 STUN 列表，由浏览器自动收集并验证候选链路。网络不适配时，可为本机本次配对自定义最多 5 个 STUN 地址（每行一个），或选择不使用 STUN；两端可使用不同配置。自定义地址只留在本机页面，重连时沿用，离开后丢弃。浏览器会向所配置的服务器查询网络地址；更换 STUN 不保证直连成功，失败时仍可使用中继。选择“仅使用中继”后不查询 STUN。

1. 设备名称默认随机生成，例如「我的设备-a3f92c」，可手动修改。配对码显示为一个字母和四位数字，例如「A-1234」，复制时自动去掉横杠；输入或粘贴时自动识别横杠、空白和大小写。配对码 5 分钟有效，成功配对后失效，每个连接仅限两台设备。

   加入连接使用一位一格的配对码输入框，默认留空且不显示占位字符，字母与四位数字之间始终显示横杠。输入后自动跳到下一格，方向键可切换，退格可删除；完整配对码可粘贴到任意一格。填完最后一位或粘贴完整代码后自动请求加入；若返回「连接已失效或不可用」，清空代码并回到第一格。创建连接可勾选「自动同意设备加入」，默认关闭；开启后，收到加入请求便自动确认，仍只接受第二台设备，不影响文件自动接收设置。

2. 双方可以发送文字或选择多个文件；再次选择会追加到待发送列表，发送前可以移除。

   授权确认区显示申请设备名称、来源 IP 和待授权状态。连接建立后，双方可查看对端名称、来源 IP，以及中继和点对点可用状态。点对点建立后显示浏览器提供的对端链路地址和端口；浏览器隐藏地址时会明确提示。来源 IP 由服务端按可信代理配置识别，与实际点对点地址可能不同。关闭调试或操作日志不影响这些信息的展示。

   创建或加入时，前端只上报浏览器提供的原始提示，后端识别设备类型、浏览器及系统版本和可获取的型号，返回整理后的摘要供授权确认和连接信息展示。浏览器可能简化或隐藏这些信息，不能作为可信身份；不采集真实主机名、MAC、序列号或设备指纹。原始 User-Agent 不写日志，设备摘要默认只保留在当前连接中；开启操作日志及设备互传模块后，相关事件会同时记录双方设备摘要，沿用日志保留时间。
3. 接收方点击「中继下载」后，浏览器立即开始下载，无需再次点击。也可复制链接交给外部下载工具；实际开始下载时发送端才上传。文件无需先完整上传，服务端不保存文件。每次完整下载后显示「下载完成」，可重新下载；点击「结束传输」使链接失效。浏览器可能根据自己的设置询问保存位置。
4. 「点对点下载」需要通过浏览器信任证书的 **HTTPS** 访问，且接收浏览器支持直接保存文件（`showSaveFilePicker`）。普通局域网 HTTP 地址（例如 `http://192.168.0.188:8787`）不显示此按钮，即使日志显示直连已建立，也需使用中继下载。本机 `localhost`、`127.0.0.1` 属于安全上下文例外，仍需浏览器支持保存接口。不接收当前文件时可点击「拒绝接收」，双方仍保持连接。

文件夹传输保留目录结构，每个文件夹最多 10000 个文件和空目录；默认并发 16，接收前及传输中可调整为 1–128。使用支持目录写入的浏览器，并通过 HTTPS 或 localhost 访问。文件名和路径不能包含控制或 Unicode 格式字符；同一文件夹内忽略大小写的重复路径、同路径文件和目录冲突会被拒绝，已有同名目录也不会覆盖。

文件区分为待发送、当前任务和已结束记录；当前传输优先显示，已结束记录默认展开，可手动收起，也可重发或移除。完整下载但链接仍有效的中继任务保留在当前列表，直到结束或取消。文件记录按本地时区显示发送时刻，悬停可查看完整日期与时间；该时间由服务端统一记录。下载链接与详细说明可展开查看，复制失败时自动展开以便手动复制。已取消、失败或完成的任务可点击右侧 × 移除，不会删除设备上的文件。速率每秒刷新，按最近三个采样区间平均显示。连接详情默认展开，显示对端来源 IP、设备信息和点对点地址，点击“连接详情”可收起。

取消或失败的直连传输会关闭旧数据通道并自动重新建立点对点连接。直连恢复后，后续文件仍可选择「点对点下载」，无需重新配对；本次取消的文件不会继续传输。

已配对设备意外断线后保留配对 5 分钟，界面显示恢复期限。返回前台时自动检查连接并重连，双方在线后恢复互传；中断的文件需要重新发送，文件夹需重新选择，不自动续传。等待恢复时立即释放传输资源、撤销旧下载链接，不在服务端积压消息。Android 浏览器切到后台或锁屏后可能暂停页面，不能保证后台持续传输。请保持传输页面在前台；刷新、页面被系统销毁、主动断开、权限撤销或超过期限后需重新配对。

接收端可勾选「自动接收对方文件」，默认关闭且仅本次连接有效。开启后，对方文件按顺序自动启动中继下载；关闭后，后续文件恢复手动确认，已开始的传输继续。浏览器自身的保存位置及多文件下载权限不受此开关控制。自动接收使用一次性地址，使用第三方下载器时请关闭自动接收，手动选择「中继下载」。

使用 **AB Download Manager** 等第三方下载工具时，接收方同样选择「中继下载」。安装并启用 [AB 官方浏览器扩展](https://abdownloadmanager.com/docs/integration?lang=en-US) 后，自动发起的下载可由扩展接管；也可「复制下载链接」后粘贴到下载工具中。支持 HEAD 文件探测、HTTP Range 分段下载和当前连接内的重试，无需本站账号或浏览器 Cookie。请将下载工具连接数设置为卡片显示的上限（最多 4 路，受管理后台中继并发设置限制）。

下载工具使用实时中继，发送页面按需读取原文件区间，服务器不缓存文件。双方页面需保持在线；刷新、离开、取消或「完成接收」会撤销链接。链接最长 30 分钟有效，闲置 10 分钟也会失效，每个文件最多 256 次实际 GET 请求，累计转发最多为文件大小的 4 倍（小文件至少 1 MiB 额度）。支持本次连接内续传，不支持离线或重新配对后继续。链接含临时下载权限，请勿转发。下载工具保存完成后点击「完成接收」，再接收下一文件；页面进度仅表示已传输数据，不代表外部工具已保存成功。完整下载后再次请求时，双方进度和速率会按新一轮重新统计，单轮分段重试不会重复计入进度，历史流量与请求次数限制保持累计。文件传完后显示「重新下载」，并可点击「完成接收」；确认完成后下载链接失效。

发送失败或取消后，发送方可点击「重新发送」，无需再次选择原文件。重发从头开始并计入会话额度；接收方未开启自动接收时，普通文件仍需再次确认。移除任务或离开页面后，本地文件引用会释放。

文字输入框支持粘贴 PNG / JPEG 图片：先显示待发送缩略图，点击「发送消息」后，对方会在聊天区自动接收。点击缩略图查看大图，支持按钮或滚轮缩放、拖动及手机双指缩放，「适应窗口」恢复初始视图。使用浏览器右键保存原图，图片消息右上角 × 可移除该消息。文字和图片消息均显示服务端记录的发送时间，页面按设备本地时区显示。图片通过本站实时中继发送，不写入服务器存储；普通大文件的原生流式下载方式不变。单张图片最多 4 MiB、419 万像素，长边不超过 4096；动态图片和更大的原图请使用文件互传。一次最多粘贴 4 张，页面仅保留最近 4 张的预览与下载数据，较早图片请及时保存。图片同样计入 32 个文件额度，并在当前传输结束后接收。

每个连接最长 2 小时、双方合计最多 32 个文件、逐个传输，默认单文件最多 10 GiB、累计申报大小不超过单文件限制的 4 倍。文字每条最多 4096 字节，页面只保留最近 100 条。断开、刷新或服务重启会取消未完成的文件，需要重新发送；不支持离线接收或跨连接续传。原生下载的“中继已转发完成”表示服务器已发出数据，最终保存结果请查看浏览器下载记录。

公网部署请使用 HTTPS。文字和中继文件通过本站转发，服务端可以接触内容，**不属于端到端加密**。直连文件由 WebRTC 加密传输，但协商可能向对方暴露网络地址；任一方勾选「仅使用中继」即可禁止直连协商。配对确认中的设备名是对方自填的名称，不是身份证明。

互传不读取已配置存储，不生成长期分享链接，也不沿用普通分享的上传暂存额度；有独立的并发、大小和带宽上限。创建者退出登录、密钥停用或权限撤销后，服务端定期复核并关闭连接。部署配置见 [部署指南](deployment.md#设备互传与实时中继)。

## 预览

支持文本、Markdown、图片、浏览器原生视频和音频预览，其他格式直接下载。媒体格式能否播放取决于浏览器编解码能力。

文本预览有读取大小限制，Markdown 默认不请求站外图片。文件读取票据有效期为 10 分钟，其间 Range 请求不会反复消耗查看次数；票据到期后重新打开分享可能消耗一次额度。

## 身份与权限

| 身份         | 登录           | 管理入口    | 范围                             |
| ------------ | -------------- | ----------- | -------------------------------- |
| 访客         | 无需登录       | 无          | 访问公开分享，按站点设置创建或加入 |
| API Key 用户 | `/login`       | `/manage/*` | 按授权创建分享，管理自己的记录   |
| 管理员       | `/admin/login` | `/admin/*`  | 管理分享、存储、密钥、账号及设置 |

API Key 登录页下方提供管理员登录链接。管理员账号使用用户名和密码；普通用户使用 API Key。

管理员可在“系统设置 → 常规 → 访客权限”分别控制创建文本、上传文件、创建互传和加入互传。默认前三项关闭、加入互传开启；已登录用户仍按账号权限使用。开关控制新的创建与加入请求，不中断已建立的互传或撤销已有分享。

访客上传只能选择公开、启用且可写的存储，文件存入独立目录；多文件仍可生成合集。访客没有分享列表、修改、删除或查看失效分享的权限，保留创建结果中的链接即可访问有效分享。文件大小、并发、临时空间及互传限频仍然生效。

从文本分享或文件分享页进入 API Key 登录，成功后返回原分享页面。直接打开登录页时，成功后默认进入文本分享页。

新增密钥时可自动生成，也可自行填写，不限制长度和字符，支持中文、空格和特殊字符，留空自动生成。输入框、创建结果及列表默认隐藏密钥，使用同一个按钮切换显示与隐藏；仅管理员可查看列表中的完整密钥，刷新或离开页面后恢复隐藏。重复密钥不能创建，编辑权限不会更换密钥。

四个权限选项分别为创建文本、上传并分享文件、管理自己的文本、管理自己的文件。还可限制存储与路径；存储未公开时普通 Key 不能使用。需要更换密钥时，创建新 Key，再停用或删除原 Key。

允许使用的存储通过复选框勾选或取消，不选表示允许使用全部公开存储。密钥有效期使用本地日期时间选择器，点击清空表示不过期。

## 操作日志

管理员可从后台“操作日志”按模块、身份、操作人、结果和日期查询记录。日期按浏览器本地时区计算，包含开始和结束日期的全天；可选每页 20、50、100、200 条，默认 50 条，切换条数后返回第一页。覆盖账号认证、文本分享、文件分享、设备互传、存储、密钥和系统设置；记录操作时间、IP、对象、接口、状态和耗时。API Key 登录验证记录为“验证 API Key”；浏览器本地清除密钥不会产生服务端退出记录。

“操作日志”位于管理菜单最后一项。“系统设置 → 日志设置”集中管理日志总开关、模块开关、保留时间和手动清理。总开关默认关闭，各模块开关默认开启；仅在总开关及对应模块开关均开启时记录新操作，保存后立即生效并在重启后保留。关闭期间已有日志仍可查询和清理。

“操作日志保留天数”默认 30 天，支持 1–3650 天。到期记录不再展示，并分批自动清理；缩短保留时间可能永久删除旧记录。同页的“清理日志”可按开始日期、结束日期和模块手动清理，包含结束日期全天，支持只清理同一天；删除前会二次确认，每次请求最多删除 1000 条，页面自动继续清理剩余记录。已进入异步队列的记录可能稍后写入。

高频重复请求会按 IP、接口和结果在一分钟内合并，列表以 `+次数` 标示；扫描不同无效路径也会合并，避免日志被持续刷大。不同来源过多时只保留模块级汇总。合并只影响日志写入，不改变请求结果或接口限频。

日志使用数据目录下独立的 `operation-logs.db`，备份时可一并保存。后台队列最多 1024 条，每批最多 64 条、约 250 毫秒写入一次；正常退出排空队列。健康检查、静态资源、列表轮询、互传心跳/进度/分段请求不逐条记录；普通文件 Range 请求也不逐条记录。互传文字逐条记录；文件与图片在接收方接受时记录开始、在任务结束时记录最终结果，包含名称、大小、发起时间、耗时及两端服务端可见 IP。下载工具中继每次完整下载另记一条“下载完成”，重复下载分别记录；链接在接收方结束传输前保持可用。点对点传输完成后，还会记录接收端浏览器上报的实际直连两端地址和端口；浏览器隐藏地址或未提供统计时，该字段可能缺失或显示“浏览器未公开”。日志查询和清理不占用业务数据库连接；队列满或写入失败时不阻塞业务，未保存数量会汇总到运行日志，因此不能作为绝不丢失的合规审计系统。

不记录密码、密钥、令牌、URL 查询参数、分享文本正文、文件内容或图片原始数据。**互传文字会记录正文**，最多 4096 字节；不要通过互传文字发送不希望留存于管理员日志中的敏感内容。配置变更保留数值、开关、站点标题的前后值，HTML、公告正文、链接等只记录修改项并隐藏内容。日志仅以纯文本展示，仅管理员可读取。

日志 IP 只采信已配置的可信代理。使用代理主机名时，日志复用有效 DNS 缓存；缓存未就绪或繁忙时记录连接地址，不额外发起 DNS 查询或阻塞请求。

“申请加入互传”和“加入互传”分别记录申请与同意两个阶段，详情显示双方设备名称、身份、账号、来源 IP、申请时间、连接编号及是否仅允许中继；同意后补充同意时间和“已同意加入”状态。设备名称由用户填写，仅用于识别显示；来源 IP 来自服务端。点对点端口在后续传输日志中记录，加入时不提前标记为已直连。

## 系统设置

| 分组     | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 常规     | 访客权限、上传上限、上传下载并发、暂存总额度、新分享默认有效期、下载安全说明 |
| 设备互传 | 互传总开关、中继速率与并发、单文件上限、STUN 服务器、点对点调试日志 |
| 安全与限频 | 密码/API Key 验证、互传连接、消息及中继的九项每分钟次数 |
| 文件预览 | 文本读取上限、支持的扩展名、站外图片开关                 |
| 站点外观 | 标题、图标、页脚、入口开关、公告和自定义 HTML            |
| 日志设置 | 日志总开关、模块开关、保留时间、按日期和模块清理日志      |

修改后需要保存；有未保存改动时，页面切换会提示。业务设置保存后无需重启，已保存的配置继续保留，原相关环境变量不再生效。单文件上传上限最大 10 GiB，暂存额度不能小于该上限。调低并发不影响已有上传和下载；关闭互传只停止创建与加入新连接。限频修改保留当前计数，STUN 对新配对生效。固定安全策略仅供查看。自定义 HTML 经过过滤，不执行脚本或事件属性。

「设备互传 → 点对点调试日志」默认关闭。保存并重新连接后，在浏览器控制台启用 Debug/Verbose 级别，筛选 `[CloudPaste P2P]` 查看双方地址和端口、选中的链路、往返延迟、协商耗时以及文件字节、耗时和平均速率。浏览器可能隐藏 IP，返回 mDNS 名称或空值。日志不包含凭证、配对码、聊天或文件内容、完整 SDP。

“站点外观 → 站点公告”可设置启用、内容和“默认显示公告”。默认展开关闭时，点击右上角公告图标查看；开启后，访问或刷新页面自动展开，手动收起后在站内切换页面不会重新展开。公告直接显示 Markdown 内容，无额外标题，留白更紧凑；未启用或内容为空时不显示公告区域和图标。

“站点外观 → 页面入口”可显示或隐藏右上角 GitHub 图标，并设置 GitHub 地址。默认指向 `https://github.com/Qwerto107/CloudPaste`，在新标签页打开；仅允许 HTTP/HTTPS 地址，留空隐藏图标。

## 外观

首次访问跟随系统主题，手动选择浅色或暗色后在当前浏览器记忆。手机端使用底部导航。

默认 CloudPaste favicon 随浏览器配色变化。站点外观里的图标 URL 可自定义标签页图标，留空恢复默认；手机主屏幕图标使用本站静态文件。
