## 创建文本与文件分享

### 文本与文件能力

- **文本分享（`/`）**：支持纯文本与 Markdown 编辑/实时预览。可直接粘贴图片或通过工具栏插入图片链接（PNG/JPEG/GIF/WebP 单张最大 1 MiB，随文本一同保存并受密码保护）。
- **文件分享（`/upload`）**：支持拖拽与批量选择，单文件默认最大 **10 GiB**；一次上传多个文件时自动组成**合集链接**，失败后重试仅处理剩余文件。

### 分享选项一览

| 选项 | 说明 |
| --- | --- |
| **自定义链接名称** | 1–100 个字母、数字、`-` 或 `_`；留空自动生成。过期或次数耗尽后可复用原后缀 |
| **有效期** | 1 / 3 / 12 小时，1 / 3 / 5 / 7 / 14 / 30 天，长期，或自定义时长（新分享默认 24 小时） |
| **访问密码** | 可选，访客需验证后查看 |
| **最多查看次数** | `0` 表示不限，正整数表示上限 |
| **文件备注** | 可选，直接在上传表单中填写 |

创建完成后，结果区提供**复制链接**、**复制分享文字**（含 `链接：` 与 `密码：` 行）和**打开分享**按钮，结果内容固定为创建时的快照。

### 管理、过期与删除

- **管理操作**：后台列表中「新增」「编辑」「预览」以弹窗打开（手机端为底部抽屉）。文件管理中改名仅修改显示名，不影响底层文件名。
- **过期行为**：过期或次数耗尽后停止公开访问，原文件默认保留；**管理员**和**创建该分享的 API Key 用户**仍可查看、预览和下载失效内容，且不消耗查看次数。
- **自动清理（可选）**：可在「系统设置 → 常规 → 分享与上传」中开启**自动清理过期分享**（默认关闭，默认保留 **180 天**），超期后后台自动回收记录与对应存储原件。
- **手动删除**：删除文件分享默认同时删除存储原件，也可取消勾选以仅删除记录；删除合集会清理全部子文件。

<details>
<summary><strong>补充说明：上传位置、密码找回与本地写入机制</strong></summary>

- **上传位置**：仅列出已启用、可写且当前账号有权限的存储；只读存储不会出现。若列表为空，请管理员检查存储的只读设置、公开标记及 API Key 授权。
- **本地上传进度**：本地存储直接写入目标目录的隐藏临时文件，校验并刷盘后原子发布（无需二次复制）。进度到 100% 显示“正在保存…”时正在等待刷盘或 S3 写入。
- **密码查看与修改**：管理员和创建者在管理页可直接查看/修改密码（预览页和预览接口永不返回密码）；旧版本仅保存不可逆哈希的记录会提示重新设置。

</details>

## 设备互传

打开 `/transfer` 即可在两台设备之间实时互发文字、图片、单文件和文件夹。

> [!WARNING]
> **隐私与加密边界**：互传不保存历史文件，但文字和中继文件会经由本站服务端实时转发，**不属于端到端加密**；公网部署请使用 HTTPS。点对点直连由 WebRTC 加密传输，但可能向对方暴露网络地址（任一方勾选「仅使用中继」即可禁止直连协商）。

### 1. 快速配对

1. **创建连接**：管理员或同时具备文本+文件分享权限的 API Key（或开启访客权限）点击「创建配对码」，生成 **4 位数字配对码**（5 分钟有效，配对成功后作废）。
2. **加入连接**：另一台设备无需登录，在 4 格输入框中输入或「一键粘贴」配对码即自动发起请求。
3. **确认连接**：创建者核对设备名、来源 IP（及可选归属地）后点击「确认连接」（也可勾选「自动同意设备加入」，默认关闭）。

### 2. 发送文字、图片、文件与文件夹

- **文字与图片**：在输入框按 `Enter` 发送文字，或直接粘贴 PNG / JPEG 图片（单张最大 **4 MiB**、419 万像素，长边 ≤ 4096；页面保留最近 4 张预览，点击可缩放查看）。
- **单文件**：点击附件按钮或直接拖入聊天区，可多选排队，失败或取消后可直接点击「重新发送」。
- **文件夹**：保留完整目录结构（最多 **10,000** 个文件和空目录），默认并发 **16**，接收前及传输中可动态调整为 **1–128**。接收端需使用 **HTTPS**（`localhost` 例外）及支持目录写入（`showDirectoryPicker`）的浏览器。

### 3. 点对点直连 vs 实时中继（含下载工具）

| 方式 | 适用条件 | 特点 |
| --- | --- | --- |
| **点对点下载** | 需受信 **HTTPS**（或 `localhost`）+ 浏览器支持 `showSaveFilePicker` | 浏览器间 WebRTC 直连落盘，不经服务器流量；普通局域网 HTTP 地址不显示此按钮 |
| **中继下载** | 任意 HTTP/HTTPS 浏览器 | 服务端零暂存实时转发，接收端点击后发送端才开始上传 |
| **外部下载工具** | 点击「中继下载」后复制链接，或配合 [AB Download Manager 扩展](https://abdownloadmanager.com/docs/integration?lang=en-US) | 支持 HEAD、HTTP Range 分段与连接内重试（最多 4 路并发）；下载完成后点击「结束传输」撤销链接 |

- 接收端可勾选「自动接收对方文件」（仅本次连接有效），开启后按顺序自动触发中继下载；使用第三方下载工具时建议关闭此开关。

### 4. 断线恢复与容量限制

| 项目 | 限制 / 行为 |
| --- | --- |
| **房间时长** | 最长 2 小时，仅限 2 台设备 |
| **任务额度** | 双方合计最多 32 个逻辑任务（单个文件夹算 1 个逻辑任务） |
| **文件大小** | 单文件默认最大 10 GiB；单次连接累计申报大小 ≤ 单文件上限 × 4 |
| **文字消息** | 单条最多 4096 字节；页面保留最近 100 条 |
| **意外断线** | 默认保留配对 **5 分钟**（后台可配 0–60 分钟），返回前台自动重连；中断的文件需重新发送，不支持离线续传 |
| **刷新 / 离开** | 尽力通知服务端结束配对；切到后台不主动退出（但移动端系统可能暂停后台传输） |

### 5. 高级连接设置与 IP 归属地

- **STUN 设置**：「高级连接设置」默认使用站点 STUN 列表，也可临时选择内置 STUN 或关闭 STUN（仅本机本次生效）；勾选「仅使用中继」时不查询 STUN。
- **IP 归属地（可选）**：管理员可在「系统设置 → IP 归属地」手动上传 IP2Location LITE DB3 IPv4 BIN 文件，加载后在配对确认与连接详情中显示 IPv4 国家/省份（IPv6 不显示）。详见 [部署指南：可选 IP 归属地数据库](deployment.md#可选-ip-归属地数据库)。

> CloudPaste uses the IP2Location LITE database for [IP geolocation](https://www.ip2location.com).

<details>
<summary><strong>补充说明：设备信息识别、下载工具额度与文件区交互</strong></summary>

- **设备摘要**：配对时前端仅上报浏览器提示，由后端整理为可读摘要供核对；不采集主机名、MAC、序列号或设备指纹，原始 User-Agent 不写日志。
- **下载工具链接有效期**：最长 30 分钟有效、闲置 10 分钟失效；单文件最多 256 次 GET，累计转发 ≤ 文件大小 × 4（至少 1 MiB）。
- **文件列表交互**：分为待发送、传输中、已结束三区；已取消/失败/完成的任务可点 `×` 移除记录（不删本地文件）；连接断开后聊天记录会保留至刷新或新配对。
- 更多服务端容量与反代配置见 [部署指南：设备互传与实时中继](deployment.md#设备互传与实时中继)。

</details>

## 在线预览

- **原生支持**：文本、Markdown、图片、浏览器原生视频与音频；其他格式直接提供下载。
- **安全与计次**：文本预览有大小上限，Markdown 默认不加载站外图片；单次打开签发的读取票据 **10 分钟**内有效，期间音视频拖动（Range 请求）不会重复消耗查看次数。

## 身份、权限与 API Key

| 身份 | 登录入口 | 管理入口 | 权限范围 |
| --- | --- | --- | --- |
| **访客** | 无需登录 | 无 | 访问公开分享；按站点「访客权限」开关决定能否创建分享或互传 |
| **API Key 用户** | `/login` | `/manage/*` | 按分配权限创建分享、管理自己的文本/文件记录 |
| **管理员** | `/admin/login` | `/admin/*` | 管理全站分享、存储、API Key、账号、日志与系统设置 |

### 访客权限
在「系统设置 → 常规 → 访客权限」中可独立开关 4 项能力：创建文本（默认关）、上传文件（默认关）、创建互传（默认关）、加入互传（默认开）。访客上传只能写入公开可写存储的隔离目录，且没有管理或查看失效分享的权限。

### API Key 管理
- **密钥生成**：支持自动生成或自定义任意字符（含中文、空格）；列表默认隐藏明文，仅管理员可按需切换显示。
- **权限粒度**：可分别勾选创建文本、上传文件、管理自己文本、管理自己文件，并限制允许使用的存储和路径范围（不选存储表示允许全部公开存储）。
- **更换密钥**：编辑权限不会更换已有密钥；需要轮换时请新建 Key 并停用/删除旧 Key。

## 操作日志

管理员可在后台「操作日志」按模块、身份、操作人、结果和日期筛选记录，覆盖认证、文本、文件、互传、存储、密钥与系统设置。

- **默认关闭**：在「系统设置 → 日志设置」中开启总开关及所需模块开关后立即生效。
- **保留与清理**：默认保留 **30 天**（可设 1–3650 天），到期自动分批清理；同页支持按日期范围和模块手动批量清理。
- **隐私脱敏**：绝不记录密码、密钥、令牌、URL 查询参数、分享文本正文或文件内容。

> [!WARNING]
> **互传文字会记录正文**（单条最多 4096 字节）。开启互传日志时，请勿通过互传文字发送不希望留存于管理员日志中的敏感信息。

<details>
<summary><strong>底层机制：独立数据库、日志合并与异步写入</strong></summary>

- 日志写入数据目录下独立的 `operation-logs.db`，不占用业务数据库连接；后台采用 1024 条有界队列异步批量落盘，队满不阻塞业务（因此不适合作为强一致合规审计系统）。
- 同一 IP 一分钟内的高频重复请求及扫描无效路径会自动合并（以 `+次数` 展示），防止日志膨胀。
- 健康检查、静态资源、普通文件 Range、互传心跳与分段请求不逐条记录；文件与图片仅记录开始与终态元数据。

</details>

## 系统设置与外观

| 设置分组 | 主要配置项 |
| --- | --- |
| **常规** | 访客权限、新分享默认有效期、**过期分享自动清理与保留天数**、上传上限、并发与暂存额度 |
| **设备互传** | 互传开关、中继总速率与并发、单文件上限、文件夹默认并发、STUN 列表、点对点调试日志 |
| **安全与限频** | 密码/API Key 验证、互传连接、消息及中继的 9 项每分钟频率限制 |
| **文件预览** | 文本预览上限、支持预览的扩展名列表、站外图片开关 |
| **站点外观** | 站点标题、图标 URL、Markdown 页脚、页面入口开关、站点公告、GitHub 链接、自定义 HTML |
| **日志设置** | 日志总开关、各模块开关、保留天数与手动清理 |
| **IP 归属地** | 手动上传、更新或卸载 IP2Location LITE DB3 IPv4 数据库 |

- **实时生效**：业务设置保存后无需重启；自定义 HTML 会自动过滤脚本与事件属性。
- **主题与外观**：首次访问跟随系统浅色/暗色主题，手动切换后在当前浏览器记忆；移动端自动适配底部导航栏与抽屉面板。
- **点对点调试**：在「设备互传」中开启「点对点调试日志」后，可在浏览器控制台（Verbose 级别）筛选 `[CloudPaste P2P]` 查看协商链路与速率统计。
