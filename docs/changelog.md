# 更新记录

[文档中心](README.md) · [产品首页](../README.md)

## 0.8.8

- STUN、上传/下载并发、暂存额度、互传开关及限频统一改为后台设置；原对应环境变量不再生效，保留已保存的设置及现有默认值。
- 文件夹中继预留及并发调整增加超时回收，避免空闲任务占满通道，实际传输并发保持不变。
- 单个文件夹最多 10000 个文件和空目录，内部消息按来源 IP 共享限频，IPv6 按 `/64` 聚合。
- 上传和互传拒绝 Unicode 格式字符；服务端拒绝文件夹内忽略大小写的重复路径及同路径文件/目录冲突。

## 0.8.7

- 互传提示改为弹出通知，优化公告样式和单行、多行对齐。
- 修复互传限频表满后拒绝所有新来源的问题，IPv6 按 `/64` 聚合，无效票据使用独立限频表。
- API Key 增加独立的失败验证限频，默认每来源每分钟 10 次，不改变现有密钥规则。
- 移除页面中的 IP 数据库署名提示，来源说明保留在文档中。

## 0.8.6

- 分享有效期支持快捷按钮和自定义时长。
- 文件夹互传保留目录结构，支持排队、并行传输和逐文件进度；默认并发 16，接收前及传输中可调整为 1–128。
- 优化互传界面，显示文件夹总速率，等待连接时也可开启自动同意。
- 中继总并发默认 64，后台可自定义，0 表示不限；文件夹使用独立限频，修复同一浏览器多标签页中继卡住的问题。
- 文件夹日志按整体开始、结束汇总，保留数量、大小、耗时、连接信息及失败路径，避免逐文件刷日志。

## 0.8.5

- 系统设置支持手动加载、更新和卸载 IP2Location LITE DB3 IPv4 数据库，归属地同时用于互传与相关日志。
- 文件列表按待发送、当前任务和已结束记录分区，显示发送时间；连接详情与历史默认展开。
- 修复内嵌前端遗漏下划线辅助模块，导致动态页面加载失败的问题。
- 补充 Nginx HTTPS、WebSocket、真实 IP 和关闭中继缓冲的部署示例。

## 0.8.0

- 单容器与完整程序支持五种 Linux 架构，完整程序还支持 Windows amd64 和 macOS arm64。
- 清理前端不再调用的 API、旧渲染模块、未引用函数与字段，补充当前 HTTP API、WebSocket 协议和环境配置文档。
- 过期或查看次数耗尽的分享释放自定义链接后缀，保留原记录与文件，旧票据不能读取替换后的分享。
- 单文件上传默认最大 10 GiB；文本支持粘贴图片和插入图片链接，嵌入图片经过大小与格式校验。
- 删除文件分享默认同时删除存储中的原文件，支持选择仅删除记录；合集可清理全部子文件。
- 管理员及创建者可查看、预览和下载失效分享，显示失效原因且不消耗查看次数；其他用户仍受公开访问限制。
- 管理界面支持查看、直接修改分享密码。新建及重新设置的密码保存验证哈希和加密副本，旧哈希密码仍可验证，但需重新设置后才能查看。
- 创建结果支持复制链接、复制包含密码的分享文字和手动选择复制，统一操作按钮与布局；分享预览页不展示密码。
- 互传配对码改为字母加四位数字，页面显示 `A-1234`、复制为 `A1234`。分格输入填满后自动加入，失效自动清空；创建连接可选自动同意设备。
- 修复中继上传完成后取消回调影响连接复用的问题，避免后续请求收到空响应。
- 取消跨 IP 的每分钟总次数，创建和加入连接各默认每 IP 每分钟 30 次，普通中继上传、下载共享每 IP 每分钟 180 次；全部限频项可通过环境变量配置。
- 公告去掉额外标题、减少留白，支持默认展开；右上角新增可配置地址和显隐的 GitHub 链接，更新默认版权页脚并去掉重复字数统计。

升级前后保留数据目录、`encryption.key` 和文件存储，前后端使用相同版本。**删除文件分享的默认行为已改为删除原文件**，需要保留文件时选择仅删除记录。旧客户端应按 [API 文档](api.md) 同步已精简接口；没有加密副本的旧分享密码无法还原，重新设置后可在管理界面查看。全站并发、容量与带宽保护继续保留。

## 0.7.0

- 新增设备互传：短期配对码、双方确认连接，同一页面互发文字、图片与文件；网站进程和端口内置配对、WebSocket 与 HTTP 中继能力。
- 支持 WebRTC 点对点写盘与实时中继；使用固定缓冲、背压和写盘确认，大文件无需完整进入浏览器或服务器内存，服务器不缓存互传文件。
- 中继下载统一浏览器和外部下载工具入口，支持 AB Download Manager、文件探测、分段、当前连接内重试和重新下载；每轮双方进度重新统计，完成接收后撤销链接。
- 新增自动接收、失败重发、追加文件、任务移除和粘贴配对码；取消点对点任务后自动恢复连接，后续文件仍可使用直连。
- 支持粘贴图片聊天、发送时间、等比例缩略图与大图缩放拖动，限制图片大小、像素与保留数量，断开后释放预览。
- 后台增加设备互传保护设置，可保存中继总速率、并发请求数和单文件上限；保留身份、配对尝试、票据期限、流量与并发限制。
- 文本和文件管理显示分享有效状态及失效原因，统一操作按钮大小；互传页面使用状态和传输方式标签，优化两种主题下的布局与文案。
- 同步两套 Docker 部署的 WebSocket 和流式代理配置，发布检查覆盖配对、原生下载、真实 WebRTC 写盘及中继分段流程。

升级时保留完整数据目录、`encryption.key` 和文件存储，前后端使用相同版本。升级或刷新会断开当前互传连接；临时下载链接需要双方页面在线，不支持跨连接或离线续传。

- 待上传文件支持移除，重新选择文件追加到队列，列表布局更紧凑。
- 按需加载 Naive UI 控件与 Markdown 编辑器，统一按钮、输入框和图标，管理后台支持日期时间选择与 Markdown 编辑、预览。
- 修复文本编辑时意外插入内容、控件对齐和动态样式加载问题；内嵌页面正确处理安全策略和响应长度。
- 密码验证后的临时凭证在当前标签页保留 10 分钟，刷新无需重复输入密码，不保存明文密码。每次成功打开或刷新仍计数，达到查看上限后拒绝访问。

升级时保留完整数据目录、`encryption.key` 和文件存储，前后端使用相同版本。公开分享失效响应统一为 `NOT_FOUND`，第三方客户端应同步处理。

- 改进系统设置开关、格式输入与 HTML 编辑控件，适配手机操作。

## 0.5.0

- 新增前后端合并镜像 `cloudpaste-standalone` 与 Linux amd64 / arm64 单文件程序。前端资源嵌入 Go 二进制，同一端口提供页面与 API；保留原有分离部署产物。
- 静态页面使用独立的内容安全策略，支持页面路由刷新和资源缓存；未知 API 不回退为页面，不提供目录列表或磁盘文件访问。
- 密码尝试与下载限流按可信代理链识别来源，默认忽略客户端伪造的转发头；分离版 Compose 只信任内部前端服务。
- Windows LOCAL 存储拒绝大小写、8.3 短名称、尾点等文件别名，防止绕过路径密码。
- 下载增加单来源并发额度与持续写入超时，防止停读连接长期占用全局下载容量。
- Markdown 过滤表格背景图片属性，修复关闭站外图片时仍可能发起外部请求的问题。
- 发布流程增加合并运行版的浏览器、Docker 和双架构构建检查，提供四份二进制压缩包及校验文件。

升级时保留完整数据目录、`encryption.key` 和文件存储。使用外部代理时按部署指南配置可信地址；Windows 路径配置须与磁盘实际名称和大小写一致。切换合并与分离模式前停止原服务，避免两套进程同时使用同一数据库。
