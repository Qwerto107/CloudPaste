# 文档中心

[产品首页](../README.md) · [English](en.md)

CloudPaste 是面向 Docker 和独立服务器的临时文本与文件分享站。按使用场景选择文档：

| 文档 | 内容 |
| --- | --- |
| [使用指南](usage.md) | 分享、预览、密钥权限、账号与系统设置 |
| [部署指南](deployment.md) | Docker、目录权限、资源限制、反向代理与升级 |
| [二进制部署](binary.md) | Linux 前后端单文件程序、独立后端与数据目录 |
| [API 参考](api.md) | 按访客、API Key、管理员区分的接口与参数 |
| [开发指南](development.md) | 本地服务、前端构建、自动检查与图标维护 |
| [发布流程](releasing.md) | 双架构构建、镜像标签和 Release 附件 |
| [更新记录](changelog.md) | 版本改动 |

镜像部署的 Docker 命令在自行创建的运行目录执行，源码构建命令在仓库根目录执行。界面展示图片位于 `docs/assets/`；`product-showcase.png` 为产品效果图，其余为使用演示内容的实际截图。
