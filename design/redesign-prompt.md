# CloudPaste 界面改版：完整实现提示词

> 对照效果图：`design/cloudpaste-ui-v3.html`（顶部深色条可切换页面、手机视图）。
> 项目：`D:\project\CloudPaste`，Vue 3 + Vite + naive-ui 前端，Go 后端。
> 原则：**功能、接口、字段、文案与现有组件保持一致，只重排结构和视觉**；不删任何已有功能；不编造数据。

---

## 0. 实现方式（重要）

- 不能只在旧组件上叠加 CSS。每个页面要**按效果图重排模板结构**（DOM 层级、区块顺序、栅格），再写样式。
- 新样式放 `frontend/src/sharing/theme-vivid.css`（在 `style.css` 之后加载）或组件 `scoped` 样式。
- **窄屏规则必须写在宽屏规则之后**，或宽屏规则用 `@media (min-width: …)` 限定，避免覆盖（曾出现过两列规则覆盖 900px 单列规则，导致手机消息宽度为 0）。
- 所有动画放在 `@media (prefers-reduced-motion: no-preference)` 内。
- 断点：手机 `≤ 650px`（部分布局 `≤ 720px` / `≤ 900px` 沿用现有）。

## 1. 设计规范

### 1.1 配色（四个功能区主题色，切页面时整页切换）
由 `App.vue` 写入 `html[data-section]`（text / file / transfer / admin）。

| 功能区 | 主色 → 渐变第二色 | 浅底 | 暗色主色 → 第二色 | 暗色浅底 |
|---|---|---|---|---|
| 文本分享 | `#6366F1` → `#8B5CF6` | `#EEF0FF` | `#818CF8` → `#A78BFA` | `#1F2147` |
| 文件分享 | `#0EA5E9` → `#6366F1` | `#E3F4FD` | `#38BDF8` → `#818CF8` | `#0F2A3A` |
| 设备互传 | `#10B981` → `#0EA5E9` | `#DCF6EC` | `#34D399` → `#38BDF8` | `#0F2E24` |
| 后台管理 | `#F97316` → `#EC4899` | `#FFEEE2` | `#FB923C` → `#F472B6` | `#36210F` |

中性色：背景 `#F6F7FB`、卡片 `#FFFFFF`、次级底 `#F3F5FA`、线 `#E7E9F1`、正文 `#101326`、次要文字 `#626A86`。
暗色：背景 `#0B0D17`、卡片 `#131628`、次级底 `#1A1E35`、线 `#262B47`、正文 `#EEF0FF`、次要 `#99A0C2`。
状态色：成功 `#059669 / #DCF6EC`，警告 `#D97706 / #FEF3C7`，错误 `#DC2626 / #FEE2E2`（暗色 `#34D399 / #FBBF24 / #F87171`）。

- 页面顶部背景：主题色 13% 的径向光晕，向下淡出到背景色（暗色再加一团第二色光晕）。
- **不要**：标题左侧的渐变色块、卡片左侧竖色条、卡片顶部 3px 色条（圆角处会弯成弧）、大面积渐变卡片底。

### 1.2 字体与尺寸
- 正文 13.5px；页面大标题 24px / 750；卡片标题 14px / 700。
- 等宽：配对码、IP、链接、数字、时间。
- 控件紧凑：按钮高 32px（小 26px，大 34–38px），输入框高 32px，圆角按钮/输入 6–8px、卡片 14px。
- 手机端控件加大：按钮/输入 40–44px，底部主按钮 46px。

### 1.3 组件样式
- **主按钮**：主题色渐变 `linear-gradient(135deg, 主色, 第二色)`，白字，同色阴影；悬停略亮并上浮 1px；按下 `scale(.95)` 回弹。
- **次按钮**：白底细边框，悬停边框与文字变主题色。危险按钮：透明底红字红边。
- **开关 / 勾选框**：选中为主题色渐变；开关滑块带弹性 `cubic-bezier(.34,1.56,.64,1)`。
- **下拉**：naive-ui 自定义下拉（不用原生 select 样式），圆角、阴影、展开动画，选中项带对勾，支持键盘与 Esc。
- **数字输入（并发数等）**：`− [数字] +` 步进器，范围 1–128，越界自动夹回。
- **标签**：圆角 5px，小号；状态标签前带圆点。
- **卡片**：圆角 14px，细线 + 柔和阴影 `0 1px 2px #1013260a, 0 10px 30px -20px #10132633`。
- **Toast**：右上角滑入，左侧不用色条。
- **弹窗**：桌面居中；手机改底部抽屉（顶部拖动条，从下滑入）。

### 1.4 动效时长
120ms（按下/复制）、150–200ms（悬停/聚焦）、320ms（卡片出现/指示条滑动）、480–600ms（大状态变化）。
进入用 `cubic-bezier(.2,.8,.2,1)`；不做花哨的弹跳，弹性只用于按钮/开关/配对码数字。

### 1.5 Logo
沿用 `public/chain-cloud.svg` 的云朵 + 链环线条图形，**形状不变**，颜色改为 `#2563EB`（暗色 `#5B8CFF`），页头不垫色块。

## 3. 文本分享（`HomeView.vue`）

**桌面布局**：左编辑器（自适应宽）+ 右侧栏 288–320px（吸顶）。
- **编辑器卡片**：顶部大号标题输入框（无边框，“标题（可选）”）；工具栏：加粗/斜体/删除线/标题/引用 | 无序/有序列表/表格/行内代码/代码块 | 链接/图片 | 撤销/重做，右侧“编辑 / 分栏预览”分段切换 + 全屏；分栏预览时左右两栏、过渡展开；底部状态栏“N 字 · Markdown · 支持粘贴图片 单张 ≤ 1 MiB”。
- **右侧“分享设置”卡**：链接名称（前缀 `/p/` 的输入组）、有效期、访问密码开关（打开后展开输入框，高度过渡）、限制查看次数开关（展开“N 次后失效”）、主按钮“创建分享”、下方小字“Ctrl + Enter 快速创建”。
- **有效期**：按钮网格每行 4 个：1 小时 / 3 小时 / 12 小时 / 1 天 / 3 天 / 5 天 / 7 天 / 14 天 / 30 天 / 长期 / 自定义（占两格）。选“自定义”展开“数字 + 单位（分钟/小时/天/周/月/年）”，最短 1 分钟、最长 100 年。下方提示“将于 xx 失效”或“不会按时间失效”。
- **创建成功**：结果卡在侧栏原地出现（上浮 + 淡入），对勾描线动画；链接框（等宽、主题色）+ 复制按钮（点后变“已复制”）；“复制分享文字 / 二维码 / 打开”三个按钮，二维码可展开。不跳页。

**手机布局**：编辑器占满可视区；设置卡隐藏；底部固定一条操作栏：左“设置摘要”（如“1 天 · 无密码 · 不限次数”，点开从底部抽屉弹出完整设置）+ 右主按钮“创建分享”；结果卡以底部抽屉弹出。

## 4. 文件分享（`UploadView.vue`）

**桌面**：左放置区 + 文件列表，右侧“上传设置”卡。
- **放置区**：虚线框，主题浅底到白的渐变；中间主题渐变色图标块（上传箭头），“拖入文件，或点击选择”，小字“单次最多 30 个 · 单文件 ≤ 10 GiB”，按钮“选择文件”。拖入时边框变实色、区域放大 1%、图标上浮；悬停时虚线流动。
- **文件行**：类型图标块（按类型着色：PDF 红 `#EF4444`、视频紫 `#8B5CF6`、图片天蓝 `#0EA5E9`、压缩包琥珀 `#F59E0B`、文档绿 `#10B981`、音频粉 `#EC4899`，其他主题色）+ 可编辑文件名 + 大小 + 状态/移除按钮 + 进度条（同类型色，传输中带流动斜纹）。上传中图标外有扩散光环；完成后图标变绿色对勾并弹一下（完成后在列表停留，不要立即移除）；失败红色。逐行进入、错开 40ms；移除时向右淡出。
- **空列表**：小插画 + “还没有选择文件”。
- **上传设置卡**：存储位置（下拉）、合并为文件合集开关（展开合集名称）、链接名称（`/file/` 前缀）、有效期（同文本页）、访问密码、限制查看次数、备注（“仅自己和管理员可见”）、主按钮“上传并分享” + 上传中显示“取消”；底部小字“N 个文件 · 总大小”。取消后已完成的不重传，按钮变“重试剩余文件”。
- **结果卡**：同文本页（单文件“文件分享已创建”，多文件“文件合集已创建 · N 个文件 · 大小 · 到期”）。

**手机**：同文本页的底部“设置摘要 + 上传并分享”和底部抽屉；文件行隐藏大小列。

## 8. 后台管理（`AdminLayout.vue` / `AdminView.vue` / `AuditView.vue` / `SettingsView.vue`）

**保持原有字段、按钮、文案、权限逻辑不变**，只换样式和排版。

- **左侧导航卡**（196–220px，吸顶）：分组标题“分享管理 / 系统管理”；文本管理、文件管理、存储管理、密钥与权限、系统设置（展开子项：常规、文件预览、设备互传、安全与限频、IP 归属地、站点外观、日志设置）、账号管理、操作日志。选中项主题浅底 + 主题色文字。

- **列表卡**：工具栏“筛选当前列表”输入框 + 右侧主按钮（文本/文件“创建分享”，存储“新增存储”，密钥“新增密钥”）。表格：表头浅底小字；行悬停浅底；加载时骨架屏，行逐条进入。

  - 密钥列：名称（下方密钥值，可切换显示）、状态/权限、操作（显示密钥 / 编辑 / 删除）。
  - 分页“上一页 / 第 N 页，共 M 条 / 下一页”。
- **编辑表单**：在列表上方展开的面板（不是弹窗），字段与原代码完全一致（存储 LOCAL/S3 字段切换、Path Style、公开、只读、状态、备注；密钥名称、自定义密钥+显示、权限 fieldset、允许使用的存储、授权路径、有效期+清空、启用；分享标题/文件名、文本 Markdown 编辑器、备注、访问密码〔占位“原密码不可恢复，输入新密码 / 未设置，直接输入即可修改”〕、最多查看次数、**“取消现有密码保护”默认不勾选**、有效期+清空）。保存后新记录旁出现小圆点提示。
- **新密钥**：保存后列表上方出现“保存新密钥”面板（显示/隐藏、复制、关闭）。
- **删除确认**：弹窗（手机底部抽屉）；文件删除带“同时删除存储中的原文件”（默认勾选）。
- **系统设置**：分组卡片，组标题；每项左侧名称 + 说明，右侧控件（开关/数字+单位/下拉/文本/多行）；修改后底部弹出“有未保存的修改 · 撤销 / 保存设置”吸底条。
- **操作日志**（按原 AuditView）：页头说明“正在记录操作日志；保留 N 天。新记录可能稍有延迟。”+ “日志设置”；分类横向标签（全部日志 + 各模块）；筛选卡（身份 / 操作人 / 结果 / 开始日期 / 结束日期 / 查询）；表格列：时间、模块、操作（同类合并显示“+N”）、操作人、IP、结果、详情（“查看/收起”）。**详情**在行下方以高度过渡展开，同时只开一条：第一行身份标签、操作人、方法标签、接口地址（等宽）、HTTP 状态标签、耗时；第二行操作人 ID、对象（code）；下面字段网格（长字段如文件名、设备、点对点地址、IP 归属地占整行；修改类显示“旧值 → 新值”；状态/传输方式/授权状态用标签）。**不加原始 JSON**。底部“每页 20/50/100/200 条 + 分页”。
- **手机**：侧栏改顶部横向滚动胶囊标签；表格改卡片（标题一行，次要信息用“·”连成一行，操作按钮在右侧）；新建按钮改右下角悬浮圆形按钮。
